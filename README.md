# 🍔 Food Delivery Cost and Profitability Analysis Using Python

This project presents a detailed analysis of the cost structure and profitability dynamics within a food delivery service using Python and real-world transaction data. It is designed to help stakeholders identify cost drivers, assess profitability patterns, and simulate changes in pricing strategies to enhance business performance.

## 🚀 Features

- **Data Cleaning & Preparation**: Handles date parsing, missing values, and discount string parsing.
- **Cost Breakdown**: Computes delivery, processing, and discount costs per order.
- **Profitability Analysis**: Calculates revenue, costs, and profit per order.
- **Visualizations**:
  - Profit distribution histogram
  - Cost composition pie chart
  - Revenue vs. Cost vs. Profit bar chart
- **Strategic Recommendations**: Suggests optimal commission and discount rates to improve profits.
- **Advanced Insights**:
  - Correlation heatmaps
  - Delivery duration trends
  - Customer and restaurant performance
  - Payment method impact
  - Clustering-based customer segmentation
  - Anomaly detection using Isolation Forest
- **Time Series Analysis**: Weekly trends and order density heatmaps.

## 🧪 How to Use

1. Clone this repository.
2. Ensure `food_orders_new_delhi.csv` is in your working directory.
3. Install required libraries:
   ```bash
   pip install pandas matplotlib seaborn plotly scikit-learn
   ```
4. Run the script or notebook to explore the analysis.

## 📊 Key Insights

- Profitable orders tend to have around **30% commission** and **6% discounts**.
- High refund rates and long delivery durations negatively affect profitability.
- Weekday and hourly patterns show demand concentration and can guide staffing/delivery planning.
